## 2026-07-29 — One predicate decides Stripe access, and admin stays on laqy69@gmail.com

**Decision:** (1) **`isBillingAllowedForCheckout` in `api/_shared/billingAccess.ts` is the single answer to "may this user reach Stripe"** — env switches (`STRIPE_BILLING_ENABLED` / `STRIPE_BILLING_SANDBOX_ENABLED`) → `app_metadata.{is_test_user,stripe_tester}` → an `admin_roles` probe. `/api/entitlements` derives `billing_available` from it instead of `profiles.role`, so the /plans Subscribe buttons can never promise what the checkout endpoint would refuse. ## 2026-07-27 — Pricing directives (Robert, voice feedback on the Codex tier proposal): 3x-cost pricing, weekly tier, no rollover
**Status:** active — the pricing conversation's frame; concrete prices pend the cost research (same session)
**Decision:** (1) **Pricing method:** measure real provider cost per feature (±20% precision is enough), price the subscription at roughly **3x cost**, rounded up to a friendly number. Growth beats margin — never lose money per user, but don't optimize for profit at beta. (2) **Tier structure:** two paid tiers — a cheaper low-credit tier for casual (5-min/day) learners and a higher-credit tier — **plus a weekly subscription option**. (3) **No rollover:** subscription credit/minute grants expire at renewal (purchased top-ups keep Codex's non-expiring rule). (4) **Robert's cost anchors:** Suno music via kie.ai = 12 credits ≈ **$0.054/call** (one call returns 2 songs); premium image (GPT-image-2 via kie.ai) ≈ **$0.03**; turbo image (seedream-class) ≈ **$0.002**; Whisper transcription negligible; misc LLM prompt calls minor. Speak is the open cost: **xAI Grok is the expensive path** — needs per-minute research before its allowance is set; cheaper voice models can carry a larger minute budget on top. (5) **Lens is near-free** (Gemini 2.5 Flash): generous allowance (~100/month), text-card import/creation effectively unmetered. (6) **Simplify generation UX for standard users** — standard card / premium card / music / Speak; the creative/mnemonic/infographic image options remain as power-user extras, not the default flow. (7) Long-term cost lever noted: self-host an open-source image model on rented GPU once volume justifies it.
**Why:** Robert's read of the Codex proposal (investigations/CODEX_TIER_DESIGN_2026_07_27.md): its structure (credits = creation wallet, allowances for Speak/Lens, quotas as rails) is accepted; its TBD prices should be resolved by the simple 3x-cost rule rather than a margin-modeling exercise, because the beta's goal is usage, not revenue.
**Rejected:** Precise gross-margin modeling before beta (over-engineering at this scale); making every action one fungible coin (Codex's argument accepted); rollover of subscription grants.

## 2026-07-16 — CSS convention: -webkit-backdrop-filter FIRST, standard backdrop-filter LAST in every pair
**Status:** active — LOG 2026-07-16, commit `e7b2c98e`
**Decision:** Every paired blur declaration in source CSS writes the `-webkit-` prefixed property first and the standard property last. Never reintroduce standard-first order.

Webkit-first order makes the minifier keep BOTH properties (verified in dist: 59+59).
**Rejected:** `!important` on the declarations (Codex's proposal — nothing actually fights the cascade; it was a minifier/browser-support issue) and dropping the webkit twin entirely (old iOS Safari still reads it).

## 2026-07-10 — SRS grading is never input-gated; swipe-to-grade is the flagship gesture

**Why:** Live QA showed wrong answers ("nightstand", "suit") labeled high-confidence — an uncalibrated self-report shown as a trust marker is worse than no marker in a vocabulary app, and the failure mode that matters (confident-and-wrong) is eliminated by construction when only low can surface. The wrong answers were also partly an input problem: the model saw the whole room while the user aimed at one object.
**Rejected:** Calibrating the self-report (logprobs/multi-pass — high effort, still a soft signal displayed as fact); keeping a "medium" caution (medium is also the server's fallback default — it would spam); cropping hard to the circle with no margin (kills object edges and menu/text scans).

## 2026-07-16 — buildChips distractor convention ruled (arbiter precedent)
Build-step distractors that form grammatically valid but DIFFERENT-MEANING sentences are fine (the step is meaning-anchored by the base-language prompt); only same-meaning synonym substitutions are defects.
