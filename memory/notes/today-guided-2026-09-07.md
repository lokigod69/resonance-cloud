Design reference and owner-facing report live outside the repo under `design/today-guided/` and `investigations/TODAY_GUIDED_REFINEMENT_2026_09_07.md`.

- Lazy corpus registries are mutable: compute Today overview after selected-language import resolves. Do not memoize an empty cold-load result only on path/progress. Directory counts come from the lightweight index.
- Lesson entries open directly; Start/Resume resolves a compact account/path/lesson/vibe local draft. Pin the active lesson when completion updates recommendation. Completion screen is excluded from the task count.
- A wrong answer never silently enables Continue. Build/type reveal is explicit and assistance remains sticky through Back/resume. Microphone-free practice is explicit, never a speech pass. Going back resets the remounted task gate. B1 child metrics merge by deltas.
- Do not claim a local save before a successful write. Failed draft/completion storage remains visible and retryable. Drafts contain phase/results, no raw answers/transcripts/recordings. Progress is device-local; it is not cloud sync or an atomic cross-tab store.
- Checkpoints scope account/target-language/vibe; segment/trophy reviews scope account/path/segment/vibe. Ignore ambiguous old unscoped keys. Explicit checkpoint index makes completion idempotent. Wrong trophy cloze cannot navigate on blur or complete merely after attempts; word fallback has an explicit finish action.
- Audio uses latest-request ownership and bounded lookup; cancel on step/navigation/unmount. Temporary transport failure must not poison the missing-recording cache. Speech recording/transcription cancels on unmount and exposes localized errors.
- `guidedPhraseKeep.ts` calls `keep_guided_phrase` with a 15-second client deadline and no automatic retry. Explicit completion Keep creates/reuses one user/target-language card_text deck via `guided_phrase_decks`. Identity survives rename and cascades on delete. Server dedupe survives lost responses, validates registered audio text and target language, and creates no generation job/credit mutation. Link is `/deck/:id`.
- `20260907120000_guided_phrase_keep.sql` is applied and recorded in production. Rollback integration covers RLS/ACL, identity/rename/delete, exact phrase+target audio, repeated save, no jobs/credits. Unregistered usage coordinates save text only; strict authored provenance would require a canonical server lesson registry. Existing production guided TTS base schema is required for fresh migration replay.
- UI locales are en/de/fr, but authored explanations are English/German. Unsupported base languages consistently use the authored edition and disclose its language. Do not mix partial English glosses with German cues or claim a French lesson corpus exists.
- French A2 café crème English gloss is coffee with milk. Recorded target strings/IDs are unchanged. Validators must load authored content rather than pass over empty runtime registries: 2,500 lessons, 250 paths, 2,700 trophy cells and 100 German B1 lessons. Validate a small captioned video pilot using delayed recall before scaling. Research and limits are in the report; no claim of superiority to Duolingo or of full native content review.
