# Sir Robert's Intent Spine — Guided Today A1 Practical (Paths 1-10)

An intent spine is a language-neutral description of *what the learner is being taught to do* in each lesson, separated from the English surface that currently encodes it. It exists so that downstream Spanish, Italian, and French A1 Practical drafts anchor on teaching intent and situational context rather than translating the English wording. The English lessons in `frontend/src/data/guidedLessons.ts` remain the source of truth for English content and are preserved as-is; this document is a parallel reading layer. Each row below is a brief, not a translation, and authors of downstream languages should write the canonical A1 utterance in their language using its own native templates (e.g., Spanish "Quería...", Italian "Vorrei...", French "Je voudrais..." for I'd-like requests) rather than back-translating the English core phrase. Register hints map directly to T/V choices in Spanish (tú/usted), Italian (tu/lei) and French (tu/vous). Notes flag English-specific scaffolding, intent collisions across paths, and trophy words that won't survive a direct translation.
